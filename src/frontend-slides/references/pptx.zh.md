# PPT / PPTX → HTML

当用户提供 `.pptx` 文件要求转换为 HTML 时使用本分支。HTML → 可编辑 PPTX 请改读 [editable-pptx.md](editable-pptx.md)。演示风格、简报、生成与验证步骤仍来自 `SKILL.md`。

## 1. 抽取

在技能目录下：

```bash
uv run --with python-pptx python scripts/extract-pptx.py <input.pptx> <deck-dir>
```

`<deck-dir>` 成为输出 deck 文件夹。脚本写入：

```text
<deck-dir>/extracted-slides.json
<deck-dir>/assets/slide*-img*.*
```

若 `uv` 不可用，使用已准备好且含 `python-pptx >= 1.0` 的 Python 环境；不要安装到系统 Python。脚本会打印清晰的依赖错误，而不是静默安装任何东西。

## 2. 确认抽取结果

在生成 HTML 之前，向用户展示一份精简摘要：

- 幻灯片数量与顺序；
- 每张幻灯片标题与文本摘要；
- 图片数量，以及任何缺失/无法解码的图片；
- 若抽取了表格，给出表格维度；
- 演讲者备注存在或缺失。

请用户纠正任何要紧之处。不要静默丢弃抽取器无法理解的内容。

## 3. 转换

- 保留幻灯片顺序、全部文本、相对图片与演讲者备注。
- 把备注放进其所属幻灯片旁的 HTML 注释，例如 `<!-- notes: ... -->`。
- 把抽取出的表格渲染为真正的 HTML `<table>` 元素，而不是截图。
- 图片放在 `assets/` 下并用相对路径引用。绝不覆盖原文件。
- 应用所选密度。转换后的幻灯片若对 1920×1080 过于密集，拆成后续幻灯片，而不是缩小文字。
- 对中文 deck，设置正确的 `lang`，使用 CJK 字体栈，并重新检查标点与换行；PPT 文本常带有拉丁标点与硬换行。

在相关时说明已知限制：SmartArt、图表、动画、嵌入视频与组合形状可能被简化为文本或丢失。抽取器不是像素级精确的 PPT 渲染器。

## 4. 验证

运行 `SKILL.md` 中的常规截图检查。特别注意：

- 每张原始幻灯片都按顺序得到体现；
- 图片能从 `assets/` 加载；
- 中文文本未被裁切；
- 表格可读且未溢出；
- 备注以注释形式存在。

完成条件：每张源幻灯片都已交代清楚，且抽取器无法表示的任何内容都已向用户列出。
