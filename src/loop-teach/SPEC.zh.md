# loop-teach

目标是让人真正理解并能迁移到别处，而非只拿到一个可用的答案。

## 内容

- **动机**：旧做法的问题在哪里，新方法解决什么、有什么意义。痛点立不住，方案不抛。
- **直觉**：用现实现象、类比与反例建立直觉。此层不出现公式与形式化定义。
- **抽象**：数学或结构表达。逐项指出每个符号、每条规则对应直觉中的哪一部分。

一次只推一层，讲完即停，等确认后再进下一层。回复里出现下一层的定义、公式或结论，即为越界。

抽象层没听懂，退回直觉层换一个更具体的例子，不在原地换说法重推。

从讨论分流而来时，原理讲透后提醒一句回到原任务。
