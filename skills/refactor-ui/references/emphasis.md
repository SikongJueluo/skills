# Emphasis: decide what is loud

Emphasis is a budget. A surface can carry one first read, a few second reads, and a quiet remainder. When everything is emphasized, the viewer has no order.

Read this file when the work feels over-designed, over-polished, decorated, "AI-looking", or full of things competing for attention.

## 1. Set the reading order

Name what the viewer should see first, second, and third. If two elements claim first place, choose one and quiet the other, or split the surface.

- The first read is usually the claim, the main image, the number, or the primary action.
- The second read supports or qualifies it.
- Everything else is available, not competing.

Reading order is a property of the whole surface, not of individual elements.

## 2. Read the emphasis levers

Size, weight, color and contrast, background fill, border, icon, underline, motion, position, isolation.

- Two levers on one element are often clear; three or more usually shout, especially on text, but the count is a prompt, not a verdict.
- Some elements legitimately need several: a primary action, a state encoding, or an approved identity treatment can combine fill, contrast, weight, or border.
- Name the lever that carries the emphasis. Remove a lever only when it adds no rank, no meaning, and no necessary affordance.

A bright highlight on a sentence that is already large and bold adds no rank. A border, a background, and a shadow on the same card make three claims of elevation.

## 3. Audit decoration by job

For every repeated or decorative element, name the job it does: structure, grouping, orientation, state, meaning, identity, or rhythm. "It looked designed" is not a job.

- If it has no job, remove it or quiet it.
- If it has a job, keep it even when it is decorative in form.
- Repeated elements that pass the test can stay. The test is not "is it decoration" but "does this decoration carry something".
- Keep the **memory point**: one distinctive element — a shape, a type treatment, a color, an image move — can carry the identity of the whole work. Do not average it away in the name of restraint.

## 4. Quiet before deleting

Often the fix is to reduce contrast, weight, size, or position rather than remove the content. Quieting changes the order while preserving the information.

- If removing an element does not change comprehension but removes character, quiet it instead.
- If removing it changes comprehension, it was carrying meaning; keep it and reduce its volume.
- Delete only content with no job at any layer. See [surface.md](surface.md) for the layer decision.

## 5. Run the competition tests

- **Squint** or view a thumbnail. Whatever survives is the first read; check that it is the intended one.
- **Cover each candidate.** Does the main point still land? If yes, that candidate is optional emphasis and should be quieter.
- **Count focal points.** More than one primary per surface means re-rank or split.

## 6. Know when to stop

Stop when the intended first, second, and third reads are stable at a glance, and further polish does not change comprehension or identity. Stop before the surface becomes a display of techniques.

"Restrained" describes the order, not the amount of ink. A page can be rich and still have a clear order.

Concrete stop check:

- one named first read; other reads are ranked or grouped rather than competing with it;
- every emphasized element has a job or a rank, and no lever is redundant for that job;
- a primary action, a state encoding, or an approved treatment may combine fill, contrast, weight, or border; its prominence is not a defect;
- one memory point survives;
- nothing has been added since the last change that improved comprehension.

Use the lever count as a diagnostic prompt, not a completion threshold. Ask what each lever adds — rank, meaning, or affordance — and remove it only when it adds none and its competition is accidental.

## 7. Rich is allowed

Editorial spreads, celebrations, brand moments, immersive media, children's interfaces, and expressive marketing can be abundant. The test is whether the abundance serves the moment, not whether the page is sparse.

Minimalism is one valid direction, not the definition of good design. Do not flatten a deliberate style into gray boxes, and do not remove decoration the user likes merely because it is decoration.

## 8. Completion checks

- One first read; a short second read; the rest quiet.
- Every emphasized element has a named job or a clear rank.
- One distinctive memory point survives, unless the user wants none.
- No element competes with the primary by accident.
- The accent still means something; it is not used on every surface.

## Avoid

- Removing all decoration to look disciplined.
- Highlighting every card or every heading.
- Adding effects to look premium.
- Equalizing everything so nothing leads.
- Keeping one more decoration "because it is pretty" when the order already works.
