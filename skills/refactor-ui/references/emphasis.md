# Emphasis: decide what stands out most

Emphasis is a budget. One visual surface can have one first focal point, a few second-tier highlights, and everything else quiet. When everything is emphasized, the viewer cannot tell what comes first.

Read this file when the work feels over-designed, over-polished, too decorated, "AI-made", or like everything competes for attention.

## 1. Set the reading order

Decide what the viewer should look at first, second, and third. If two elements both compete for first place, pick one and quiet the other, or split the visual surface.

- The first glance should usually land on the claim, the primary image, the key number, or the primary action.
- Second-tier highlights support or qualify the first tier.
- Everything else stays available to look at, but must not compete with the highlights.

Reading order belongs to the whole visual surface, not to a single element.

## 2. Identify the emphasis devices

Size, weight, color and contrast, background fill, borders, icons, underlines, motion, position, isolating space.

- Two devices on one element is usually clear; three or more easily becomes shouting, especially in text. But the count is a hint, not a verdict.
- Some elements genuinely need a combination of devices: a primary action, a state encoding, or an approved brand treatment may carry fill, contrast, weight, or a border at the same time.
- Find the devices that actually carry the emphasis. Remove a device only when it adds no hierarchy, conveys no meaning, and offers no needed affordance.

A sentence that is already enlarged and bold does not gain hierarchy from a bright background too. A card carrying a border, a background, and a shadow all at once claims its elevation three times over.

## 3. Audit decoration by its responsibility

For every repeated or decorative element, state the responsibility it carries: structure, grouping, orientation, state, meaning, identity, or rhythm. "Looks more designed" is not a responsibility.

- No responsibility means remove or quiet it.
- With a responsibility, keep it even when it is decorative in form.
- A repeated element that passes the check may stay. The question is not "is it decoration" but "does the decoration carry information".
- Keep the **memory point**: one distinctive element — a shape, a type treatment, a color, or an image approach — can carry the whole work's identity. Do not sand it flat in the name of restraint.

## 4. Quiet first, delete second

Often you only need to lower the contrast, weight, size, or visual position to change the reading order while keeping the information; nothing has to be deleted.

- If removing an element would not affect understanding but would weaken the work's character, quiet it rather than delete it.
- If removing it would affect understanding, it carries meaning; keep it and lower its visual volume.
- Delete only content with no responsibility at any tier. For tier choices, see [surface.md](surface.md).

## 5. Run the competition check

- **Squint** or shrink it to a thumbnail. Whatever is still visible is the first focal point; confirm that it is the intended highlight.
- **Cover each candidate element in turn.** Is the main point still clearly conveyed? If it is, that candidate is only optional emphasis and should be quieter.
- **Count the focal points.** If one visual surface has several primary focal points, reorder it or split it.

## 6. Decide when to stop

Stop when the intended first, second, and third tiers are stably clear at a glance, and further polish would not change understanding or the work's identity. Do not let the visual surface become an exhibition of design tricks.

"Restraint" describes the order, not how much ink is used. A page can be rich in content and still keep a clear reading order.

Concrete stop checks:

- there is one clear first focal point; everything else is ordered or grouped rather than competing with it;
- every emphasized element has a responsibility or a tier, and no emphasis device is redundant for that responsibility;
- a primary action, a state encoding, or an approved treatment may combine fill, contrast, weight, or a border; being prominent is not itself a defect;
- at least one memory point survives;
- nothing has been added since the last change that improved understanding.

Treat the number of emphasis devices as a diagnostic hint, not as a gate. Ask what each device adds — hierarchy, meaning, or affordance; remove it only when it adds none and creates accidental competition.

## 7. Allow rich expression

Editorial spreads, celebrations, brand moments, immersive media, children's interfaces, and expressive marketing can all be rich. What matters is whether the richness serves the situation, not whether the page is sparse.

Minimalism is only one valid direction, not the definition of good design. Do not flatten deliberate style into gray boxes; and do not remove the parts the user likes merely because they are decoration.

## 8. Completion check

- There is one first focal point, a few brief second-tier highlights, and everything else stays quiet.
- Every emphasized element has a clear responsibility or tier.
- One distinctive memory point is kept, unless the user wants none.
- No element accidentally competes with the primary focal point.
- The accent color still means something, rather than being used everywhere.

## Avoid

- Removing all decoration in order to look restrained.
- Highlighting every card or every heading.
- Adding effects in order to look premium.
- Flattening every element so that nothing carries focus.
- Keeping one extra decoration because it "looks good" when the visual order already works.
